# /status

Leia em silêncio:

1. `_memory/current-state.md` (Onde parei, Foco agora, Painel)
2. `_memory/pendencias.md` (as abertas)
3. As notas de `_projetos/` com `status: active`

Responda em **no máximo uma página**, neste formato:

```
📍 Onde a gente está
<2 linhas: foco atual e onde o trabalho parou>

✅ Andou desde a última vez
- ...

⏳ Esperando você
- <pendência em português comum>  → trava: <o quê>

🤝 Esperando outras pessoas
- ...

👉 Próximo passo sugerido
<uma ação concreta>
```

Regras:

- Linguagem comum. Nada de "P##", "frontmatter", "bloco AUTO". Diga o assunto.
- Se não houver nada numa seção, omita a seção.
- Se o `current-state` estiver com o "Onde parei" velho (mais de 2 semanas), diga isso: o status pode estar desatualizado.
